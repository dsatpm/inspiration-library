Horizontally scrolled prototype gallery on saturated orange. Each item is a black panel containing an animated line-art wordmark, framed by a large index number bottom-right (`002`) and the item name bottom-left (`SPLIT MASK`).

The transferable rule: **give every item in a horizontal track a persistent index and a name in fixed corner positions.** The content changes, the frame does not. This is what lets a user scan a horizontal set as a catalogue rather than a slideshow — they always know which item they are on and what it is called.

The `OPEN TO WORK` lettering is drawn as concentric contour lines rather than filled glyphs. Worth noting as a technique: **outline/contour type animates well because the stroke pattern can shift without the word losing legibility**, whereas filled display type can only move as a block.

The stepped square staircase entering from the left is a pixel-art motif reused across the site. A repeated geometric motif at section transitions is a cheap way to make unrelated sections feel authored by the same hand.

A `SCROLL #` label sits top-right — a small explicit affordance for a non-obvious interaction. Horizontal sections should always announce themselves.
