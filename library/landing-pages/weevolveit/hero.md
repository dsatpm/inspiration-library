Entire page set in monospace — including a ~5rem display headline (`Your tech partner. Evolved.`). Monospace at display size is normally a mistake; it works here because the fixed advance width becomes the grid, and the dot-matrix background is set to the same rhythm.

The transferable rule: **if you commit to monospace as the display face, commit completely — background grid, nav, body, labels — so the uniform character width reads as an intentional system rather than a missing font.** Mixing mono headlines with proportional body is what makes mono look accidental.

Structural moves: nav is a floating rounded pill detached from the viewport edge, which keeps the dark ground continuous behind it; a vertical scroll-percentage readout (`000%`) pins to the right edge. The wireframe globe is monochrome so the lone magenta accent stays the only saturated thing on screen.
