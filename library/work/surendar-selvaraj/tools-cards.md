Bento layout: one tall card on the left, three smaller cards filling the right — a 2×2 grid where the left cell is merged vertically.

The transferable rule: **merge one cell of a grid to create a hero item without inventing a separate "featured" treatment.** The large card gets more copy and a tag row; the small cards get a title and one line. Same card component, same styling, different span. Far more robust than maintaining two card variants.

Each card carries a **coloured status dot beside its category label** — amber for `FIGMA COMMUNITY PLUGIN`, pink for `FRAMEWORK`, blue for `WRITING`. Colour classifies item type at a glance while the type stays monochrome. Note the dot colours are drawn from the same set used to index the site's sections, so the vocabulary is consistent.

The large card has a subtle radial lift behind it, slightly lighter than the ground. **On a dark bento grid, differentiate the hero card by luminance rather than by border or fill** — a border would break the soft-card language the other three establish.

Every card ends with the same lowercase action (`EXPLORE ↗`) in the same position, so the grid has one repeated affordance instead of four different link styles.
