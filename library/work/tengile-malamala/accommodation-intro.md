A single paragraph set at ~3rem in olive display serif, running nearly the full page width across six lines, with the section label `ACCOMMODATION` tiny above it.

The transferable rule: **a section can open with one paragraph set at display size instead of a headline plus body.** No heading exists — the paragraph *is* the heading. This works when the copy is genuinely well-written and under about 60 words; it fails immediately with filler, because at 3rem every weak clause is legible from across the room.

The full-width measure (~90 characters) violates the usual 45–75 character rule, and gets away with it because the size is large and the block is only six lines. **Measure limits scale with type size** — a long measure at 1rem is exhausting; at 3rem the eye travels the same angular distance in fewer fixations.

Colour again tonal rather than black — olive on cream, matching [[pull-quote]]. The site uses this one olive for every moment of editorial voice, so the colour itself has come to mean "brand speaking."

Enormous vertical space below before the next block. Oversized copy needs proportionally oversized margins or it reads as a mistake.
