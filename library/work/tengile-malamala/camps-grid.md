Three portrait-crop photographs in an even row, preceded by a narrow intro paragraph confined to the far-left column.

Two rules:

1. **Set the intro paragraph in a narrow column offset to one side, not centred above the grid.** At ~25% page width with a ~55-character measure, it reads as a caption to the whole section. Centred intro text above a full-width grid always looks like a page header and competes with the images.
2. **Portrait crops in a horizontal row create a stronger rhythm than landscape crops.** Tall images force vertical eye movement within each cell while the row moves horizontally — the tension is what stops a three-up grid reading as a slideshow. Landscape crops in a landscape row are visually inert.

The images carry no overlaid captions or labels — the intro paragraph names all three properties in prose instead. In photography-led hospitality, text on the image is a downgrade; naming them in the intro keeps every photograph clean while still answering what they are.

Consistent crop ratio and consistent colour grading across all three is what holds the row together.
