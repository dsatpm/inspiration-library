Full-screen overlay menu. Four items only — Home, About, Connectors, Contact — set in heavy grotesk at ~4rem, stacked flush-left with generous leading.

The transferable rule: **when a site has few destinations, set the overlay menu items at display scale rather than nav scale.** Four small links centred in a black overlay look like an unfinished modal; four huge links look like a deliberate index. Scale is what converts a menu from a utility into a page.

Each item carries a small zero-padded index (`01`–`04`) in a **different colour per item** — cyan, amber, green, red. The numbering makes the list finite and ordered; the colour coding gives each destination an identity carried from the site's section accents.

Practical details:
- Contact details (email, phone, office address) pinned along the bottom in a three-column strip. **The overlay menu is the right place for the full contact block** — it is the one surface reachable from every page.
- Theme toggle bottom-right, out of the reading path.
- Close control is a circled `×` in the same position the hamburger occupied, so the control does not move between states.
- The right portion stays a flat panel reserved for hover previews — the layout is asymmetric rather than centred, which keeps the flush-left type as the composition.
